# Before / After 对照（真实语气，非编造）

> 所有「改后」都通过 `node lint/bin/ai-flavor-lint.mjs` 复检：分数下降、且不引入新的病灶。
> 复现：
> ```bash
> node lint/bin/ai-flavor-lint.mjs --file examples/before.jsonl   # 人机味指数 72.7 / 人机味浓
> node lint/bin/ai-flavor-lint.mjs --file examples/after.jsonl    # 人机味指数 13.7 / 像人
> ```

## 1. 确认式起手（ACK）

| | 文本 | 病灶 |
|---|---|---|
| 改前 | 可以，这段代码的原理是事件循环。 | ACK 起手「可以，」= 服务器返回 200 OK |
| 改后 | 这段代码在等事件循环转一圈。 | — |

## 3. 逗号两瓣句

| | 文本 | 病灶 |
|---|---|---|
| 改前 | 摸回来了，猪就猪吧。 | 前半句状态 + 后半句结论的流水线结构 |

## 8. B 站评论：摘要机 → 观众

| | 文本 | 病灶 |
|---|---|---|
| 改前 | 1. 视频介绍了怪物猎人配装。2. 讲解了黑龙歼灭刀用法。3. 总结了救援技巧。 | 清单八股，零情绪、零细节 |
| 改后 | 第 3 分钟那个切镜太狠了... 我反复看了三次，up 主这个节奏真的懂观众 | 具体细节 + 共鸣 + 夸到点上 |

---

**判断标准**：不是「更礼貌」，而是「更像一个正在看屏幕的人」。
礼貌是客服的特征，共鸣才是人的特征。
