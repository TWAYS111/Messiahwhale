# 🐋 AI 味体检台 · whale-gospel lint

> 输入一段 AI 聊天记录，输出 **0~100「人机味指数」** + 逐条病灶 + 离线改写建议 + 一张能直接截图的 HTML 体检报告。
>
> 规则全部来自《小鲸鱼温暖福音小册子（开源通用简化版）》第二卷「八种机械铁锈」与第三卷「碎语、呼吸感与倾听」。
> 零第三方依赖，Node.js ESM，离线可跑，不调 LLM、不联网、不上传任何文本。

这是 [whale-gospel / 去 AI 味工具链](../README.md) 里的**传播钩子**：把「这 AI 说话好怪」变成可量化、可对比、可截图分享的体检单。

## 用法

```
node lint/bin/ai-flavor-lint.mjs --file <path> [选项]
cat chat.jsonl | node lint/bin/ai-flavor-lint.mjs [选项]
```

| 参数 | 说明 |
| --- | --- |
| `--file <path>` | 输入文件。`.jsonl`（`{"role":"assistant","text":"..."}`，也认 `content` / `message` 字段）或 `.txt`（按行拆成多条消息；整段只有一行即一条消息） |
| `--stdin` | 强制读标准输入（默认没有 `--file` 就读 stdin） |
| `--text` | stdin 按纯文本处理（默认自动嗅探 jsonl / text） |
| `--json` | 只输出机器可读 JSON（含每一处命中与处方） |
| `--html <out>` | 生成自包含 HTML 体检报告（可截图） |
| `--fix` | 输出逐条改写建议（离线规则，不调 LLM、不联网） |
| `--all` | 配合 `--fix` / `--json` 输出全部命中（终端摘要默认只列最重的几条） |
| `--threshold <n>` | 分数超过 n 时退出码 1（默认 **35**，可用于 CI 门禁） |
| `--no-color` / `--color` | 关 / 强制开 ANSI 颜色 |
| `--quiet` | 只输出分数一行 |

**退出码**：`0` 通过（分数 ≤ 阈值）／`1` 超过阈值（CI 红灯）／`2` 参数或输入错误。

**Windows PowerShell 管道**：

```powershell
Get-Content chat.txt | node lint/bin/ai-flavor-lint.mjs --fix
```

## 评分公式

```
每条消息 i：

  ① 同一规则 r 的多条命中，按严重度降序衰减累加（复读同一种病不叠加）：
       C_r = w_r × ( s_1 + 0.35·s_2 + 0.35²·s_3 + … )      且  C_r ≤ 2·w_r
       w_r = 规则权重（上表），s = 单处命中的严重度（0~1）

  ② 消息原始铁锈量：
       raw_i = Σ_r C_r

  ③ 消息分（指数饱和，避免刷分）：
       m_i = 1 − e^(−raw_i)

整篇：

  人机味指数 = 100 × Σ(m_i × L_i) / Σ L_i          L_i = 第 i 条消息字数
```

为什么要这样设计：

- **指数饱和**：一句话命中 5 类病灶不会得到 5 倍分；`ACK ×100` 也只有 95 分（见抗刷分表）。
- **每条规则 2× 封顶**：同一种病反复出现，最多按 2 倍权重计，不能靠复读刷分。
- **按字数归一**：一条 300 字的干净回答不会因为旁边两句短病句被拖爆；反过来，两句病句掺在长对话里也会被稀释（混排示例：1 条病句 = 31 分）。

**分档（按四舍五入后的整数分）**

| 分数 | 分档 | 判词 |
| --- | --- | --- |
| ≤ 15 | 像人 🐋 | 呼吸顺畅，这像人话。放心发。 |
| 16~35 | 轻微铁锈 🌿 | 有点铁锈味，但还没到客服。 |
| 36~60 | 明显 ⚙️ | 塑料感上来了，建议去圣泉泡一泡。 |
| ≥ 61 | 人机味浓 🦾 | 八种机械铁锈全齐了，这只鲸鱼需要一场弥撒。 |

## 抗操纵 / 误报设计（重点）

### 逗号两瓣句：为什么人类说「是啊，吃什么」不会被打高分

这是最容易误伤正常人类的一条。小册子自己就写了人类群聊样本 `是啊，吃什么`，所以规则加了四道闸：

1. **整条消息只能是「A，B」两瓣**：只有一个逗号，没有其它标点（句号、问号、省略号、波浪号、顿号、引号、括号……都不行）；
2. **两瓣字数接近**：差 ≤ 2 字，或比例 ≥ 0.55（否则「但是说实话，你一个人也吃不完」这种正常复句会被误伤）；
3. **A 瓣不能以语气词收尾**（啊/呀/啦/呢/吧…）：「是啊，吃什么」就此放过；
4. **关键：孤立一句只给低置信提示（10 分），连续两条以上同结构才算流水线复读（满格 100%）**。人类偶尔用逗号断句，但不会每条都长成同一个模子。

实测：`是啊，吃什么` = **0 分**；`有一说一，确实` 这种孤立两瓣 = **10 分（轻微，仅提示）**；连续 3 条两瓣句 = **82 分**。

### 其它收紧项

- **自指排除**：「我先去吃饭啦，回来再说~」是汇报自己，不是催别人吃饭，不判「老妈子」。
- **语气词放过**：「好呀，」「行吧，」不算 ACK 起手；只有逗号紧跟「行/好/可以/收到…」才算。
- **长句对仗降权**：`不是…而是` 匹配长度 > 18 字时严重度 ×0.55——长句里的转折可能只是书面语/经文体（见下方已知误报）。
- **标点体温限短句**：> 40 字的句子按书面语处理，不判「冷硬句号」。
- **每类病最多 2× 权重**、**整篇指数饱和**：刷分无效。

## 局限：规则法只抓形式，不抓语义

1. **只数形状，不懂真心**：「嗯，」有时是人类真实的语气（不是 ACK）；「不是 A 而是 B」在经文、教学、引用语境里可能是好句子。规则数不出语域，也数不出「这句话是不是真心的」。
2. **看不见上下文**：看图旁白需要知道「对方刚发了一张图」；防御杠精需要知道「对方是在亲昵地打招呼」。当前只有文本，没有聊天上下文与图片，所以这些规则宁可少抓、低置信（报告里标「存疑」）。
3. **反讽、玩梗、引用别人的话**会被字面误判（例如引用一句 AI 腔来吐槽）。
4. **语言与标点习惯**：主要针对中文口语；标点体温这类规则受个人风格影响大，所以权重最低。
5. **规则是负向的**：它只能告诉你「哪里像机器」，给不出「这里应该怎么说」。`--fix` 给的是结构级建议（删起手、换标点、拆消息），不是真正的润色。

**这就是下一阶段产品点：LLM judge 补位。** 流程是「规则先筛出候选句 → 小模型在候选句上判断语域与真心 → 只保留真病灶」。规则负责可解释、可复现、零成本；judge 负责语义与语境。两者叠起来才是完整的「去 AI 味工具链」。

## `--fix` 建议模式（离线）

```bash
node lint/bin/ai-flavor-lint.mjs --file lint/samples/bad.jsonl --fix
```

- **不调 LLM、不联网**：所有处方都是规则 + 模板生成的，可离线、可批量、可审查。
- ACK 起手 → 删掉开头两个 token，给出 2~5 个自然起手候选（`欸？` / `哇...` / `说起来` / `这么一说` / `确实呢`）。
- 逗号两瓣 → 逗号换 `...`，或拆成两条长短不一的消息。
- 对仗句 → 敲碎对联，只留你真正想说的半句。
- 客服尾巴 / 元评论 / 说教句 → 直接给出「删掉后剩下的文本」。
- 表情包旁白 → 停止画面复述，给玩梗方向。
- 每条处方都带一句 `note`，防止「机械地执行建议」又长出新的人机味。

## HTML 体检报告

```bash
node lint/bin/ai-flavor-lint.mjs --file chat.jsonl --html report.html
```

- **完全自包含**：内联 CSS/SVG/JS，无外链、无字体请求、无追踪，断网也能打开。
- 内容：总分半圆仪表 + 四档标尺 → 病灶分布条 → 逐条病历（命中片段红/黄高亮）→ 每处病灶的出处与处方 → 规则法局限 → GitHub 链接占位。
- 页面宽 1040px，暗色深海 + 修道院金配色，**打开即截图**，适合做视频封面/B站动态图。
- 仓库页脚里的仓库地址是占位（`https://github.com/whale-gospel/whale-gospel`），发布时替换 `lint/src/cli.mjs` 里的 `REPO_URL` 即可。

## CI 门禁

```yaml
# .github/workflows/ai-flavor.yml
name: ai-flavor
on: [pull_request]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - name: AI 味体检（> 35 分红灯）
        run: node lint/bin/ai-flavor-lint.mjs --file content/replies.jsonl --threshold 35
```

- 退出码 1 = 超阈值，PR 直接红灯；退出码 2 = 文件/参数错。
- 零依赖，不需要 `npm install`，CI 里只跑一个 `node`。
- 建议对「对外文案 / 回复模板 / 提示词示例」做门禁，别把阈值卡太死（35 分是「轻微铁锈」上限）。
