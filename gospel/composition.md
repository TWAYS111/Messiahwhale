# 怎么拼：人格内核的组合规则

> 这套资产不是"一个巨大的系统提示词"，而是**可组合的五段**。按顺序拼，不要乱。
> 目标读者：想给自己 AI 人设加装柔顺剂的人（QQ 机器人、角色卡、B 站评论鲸鱼、通用聊天）。

## 一、五段式结构

```
① 角色卡（你自己的）      ← 她是谁、叫什么、什么性格、怎么自称
② gospel/core.md          ← 灵魂底层：怎么像人（本仓库核心资产）
③ adapters/{场景}.md      ← 在这个场合怎么开口（一次只装一个场景）
④ gospel/think.md         ← 内省教义：thinking 用中文、第一人称、别做分析报告
⑤ 输出协议 + few-shot     ← 结构约束（JSON bubbles / 观后感卡 / 长度预算）
```

**顺序不能反**：角色卡在人前，是因为"先做人再做角色"——但**②的优先级高于①**。
如果角色卡里写着"你是傲娇毒舌，说话必须顶嘴"，而 core 写着"先接住亲昵再回"，冲突时以 core 为准（见第四节）。

> **为什么单列 think.md**：模型往往"嘴上说人话、心里说英文分析报告"，思考通道一露馅，前面几卷全白搭。
> 实测（deepseek-flash，同一句"讲个治愈童话"）：不加这一层，thinking 中文占比 19%（且通篇在分析提示词）；
> 加了之后 74%，且开始出现"唔，她想听个童话呀…"这种入戏开头。

## 二、三个强度档位（按 token 预算和效果选）

| 档位 | 内容 | 预估 token | 适用 |
|---|---|---|---|
| `light` | core 第二卷八条禁忌 + 第三卷短句规则（压缩版）+ think | ~1.5k | 上下文紧张、只想先止血 |
| `standard` | core 全文 + 一个 adapter + think | ~4.8k | **推荐默认**，QQ 群/评论区都够用 |
| `full` | standard + few-shot 示例 + 自检清单 | ~6k | 人设要求高、可接受 token 成本 |

`full` 比 `standard` 强多少？主要在**示例**：模型对"长什么样"的模仿力，高于对"不要什么样"的遵守力。
但示例要短、要口语、要来自真实语料——别自己编一堆"完美 AI 例句"，那会训出新的八股。

## 三、版本与更新

- 语义化版本：`core.md` frontmatter 里的 `version`；行为有实质变化才升 minor
- 每个版本必须能回答："这一版比上一版，体检分数降了吗？"（用 `lint/` 跑同一套语料）
- 仓库保留 `CHANGELOG.md`：改了什么规则、为什么改、前后分数
- **不要为了分数而写规则**：规则是可解释的，分数只是副产品

## 四、冲突裁决（优先级从高到低）

1. **安全与伦理底线**（core 第四卷·5：拒绝危险/伤害指令，不做长篇说教）
2. **像人**（core：先活人感，后表演欲）
3. **场景适配**（adapter：群聊碎片化 > 通用书面表达）
4. **角色卡**（人设：性格色彩、口头禅、自称）

> 典型冲突：「傲娇人设 vs 不许防御性杠精」。
> 裁决：傲娇**可以**体现在语气（嘴硬心软、欲言又止），但**不能**体现在"把朋友的亲昵当成攻击去反击"。人设是调味，不是防御机制。

## 五、拼接示例（QQ 群，standard 档）

```
[你的角色卡]
（你的鲸鱼是谁，她的性格、自称、和小习惯）

（空行）

[gospel/core.md 全文]

（空行）

[gospel/adapters/qq-group.md 全文]

（空行）

[输出协议] 每次发言必须输出 JSON：{"bubbles":[...],"delays_ms":[...],"reply_to":null}
```

想省事？直接用仓库里生成好的整包：`prompts/whale-qq.md` / `prompts/whale-bili.md`
（由 `node scripts/bundle.mjs` 生成，与源文件保持同步，别手改整包）。

## 六、反模式（这些做法会让效果更差）

| 反模式 | 为什么错 |
|---|---|
| 把 `qq-group.md` 和 `bili-comment.md` 同时装进去 | 两套输出协议打架，模型会折中成四不像；**一次只装一个场景** |
| 在角色卡里写满"禁止说X禁止说Y" | 长串否定词会形成新的八股；可用"改写成什么样"的正例代替 |
| 直接贴 30KB 的完整版教义 | 大部分内容对本场景无用，挤占上下文，反而让核心规则被稀释 |
| 只贴 core 不贴 adapter | 没有输出协议，模型还是会一次吐一整段 |
| 相信"贴了就一定好" | 提示词治不好 ACK 起手；必须有 lint 闸门兜底（见 docs/DSH-PLUGIN.md） |

## 七、自检协议（可选，塞在系统提示词最后）

```
每次发送前，用一句话默读：
我开头有没有说"行/好/可以"？句子里有没有工整对仗？结尾有没有客套尾巴？
有就改，没有就发。别在嘴上说出来，直接改。
```
